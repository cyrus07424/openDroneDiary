# 飛行日誌の記録項目

無人航空機の飛行日誌は機体ごとに作り、飛行記録・日常点検記録・点検整備記録を残します。このアプリの項目は、国土交通省「無人航空機の飛行日誌の取扱いに関するガイドライン」（令和5年3月31日。その後の資料でも同じ三様式が参照されています）に寄せています。

法令の適用や許可・承認の要否は機体・飛行の内容・最新の告示で変わります。記録のひな形であり、個別の法的助言ではありません。

## 機体台帳

飛行日誌は機体ごとです。`/aircraft/ui` で登録記号、種類、製造者、型式、製造番号、型式認証書番号、機体認証の区分と番号を登録します。

- 登録記号は前後の空白を除き、大文字にそろえます。同じユーザーの中で重複できません。
- 導入前の飛行時間は「製造後の総飛行時間（引き継ぎ）」に入れます。以降の飛行時間はここに加算されます。
- 点検整備の間隔はメーカー指定を優先します。指定がなければ目安の20時間です。1〜500時間の範囲で保存します。

## 飛行記録（様式1）

`/flightlogs/ui` で記録します。

| ガイドラインの項目 | このアプリの欄 |
| --- | --- |
| 登録記号・種類・型式など | 機体台帳から選択し、CSVではその時点の機体情報を出します |
| 飛行年月日 | 飛行年月日 |
| 飛行させた者の氏名 | パイロット選択または自由入力 |
| 技能証明書番号 | パイロット台帳から写し、記録ごとに保存 |
| 飛行の目的・経路 | 飛行の目的、飛行の経路 |
| 飛行禁止空域・飛行の方法 | 特定飛行の区分（空港周辺、150m以上、DID、夜間、目視外、30m未満など） |
| 離着陸場所・時刻 | 離陸・着陸の場所と時刻 |
| 飛行時間 | 離陸・着陸時刻から自動計算。手入力も可 |
| 製造後の総飛行時間 | 保存時に分単位で写します |
| 安全に影響のあった事項 | 専用欄。空なら「なし」と書けます |
| 不具合及びその対応 | 既存の不具合欄 |

特定飛行の区分で「特定飛行に該当しない」と他の区分を同時に選ぶと、該当しない方は捨てます。

飛行許可・承認番号はガイドラインの必須欄ではありませんが、特定飛行の記録で参照しやすいよう任意欄にしています。

## 日常点検記録（様式2）

飛行前に、次の9項目を「異常なし / 異常あり」で残します。

1. 機体全般
2. プロペラ
3. フレーム
4. 通信系統
5. 推進系統
6. 電源系統
7. 自動制御系統
8. 操縦装置
9. バッテリー・燃料

自由記述の結果欄は特記事項です。一覧では異常項目を先に出します。

## 点検整備記録（様式3）

点検・修理・改造・整備の年月日、場所、実施者、内容と理由、その時点の総飛行時間を記録します。総飛行時間を空にすると、選んだ機体の製造後総飛行時間を入れます。

ダッシュボードは、直近の点検整備日より後の飛行時間を間隔と比べます。超過は期限超過、残り2時間以内は間近、記録がない機体は未記録です。記録がない場合でも、製造後の総時間が間隔に近づいていれば間近または超過になります。

## 使い方

- ダッシュボード: `/dashboard`
- 機体台帳と携行用の印刷ページ: `/aircraft/ui` と `/aircraft/ui/{id}/carry`
- CSV（UTF-8 BOM、Excel向け）: `/flightlogs/export.csv`
- 同じ条件の飛行を今日の日付で複製: 飛行記録一覧の「複製」

機体を選んでいない過去の記録は、携行ページと機体別の累計から外れます。必要なら編集して機体を割り当ててください。
