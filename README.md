# 🛩️OpenDroneDiary🚁
このソフトウェアは、ドローンの飛行日誌を管理するためのオープンソースのツールです。ドローンパイロットや航空愛好家が、飛行データを追跡し、分析するための機能を提供します。

## 特徴
- 機体ごとの飛行日誌（飛行記録、日常点検、点検整備）
- 登録記号、技能証明番号、飛行目的・経路、特定飛行の区分、製造後の総飛行時間
- 日常点検9項目のチェックと、点検整備間隔（未指定時は20時間）の通知
- ユーザーごとの飛行履歴、パイロット台帳、機体台帳
- 離陸・着陸場所のテキストまたは座標
- UTF-8 CSV エクスポート、記録の複製、携行用の印刷ページ
- 総飛行時間と点検期限をまとめたダッシュボード

記録項目の対応は [docs/flight-log-compliance.md](docs/flight-log-compliance.md) を参照してください。

## インストール

### リポジトリのクローン
```sh
git clone https://github.com/cyrus07424/open-drone-diary.git
```

### ビルド
```sh
./gradlew build
```

### 開発サーバーの起動
```sh
./gradlew run
```

### ブラウザで `http://127.0.0.1:8080` にアクセスする

## 使用法
- アカウントを作成します。
- 機体台帳に登録記号と型式を登録します。
- パイロットと技能証明番号を登録します。
- 飛行記録、日常点検、点検整備を機体に結びつけて保存します。
- ダッシュボードで総飛行時間と点検期限を確認します。
- 飛行記録を CSV で書き出すか、携行用ページから印刷します。
